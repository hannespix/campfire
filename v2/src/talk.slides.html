25–27 · Take the checks as if you were trying them on a laptop at a studio desk. Can you find the right control? Can you place and remove something without losing all the other objects? A standalone HTML file is a practical scope for this particular first experiment. A shared team service would have a different acceptance test and a different deployment setup.
