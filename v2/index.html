Keep the local PDF, Booth Builder and PixiNotes open. To rehearse the live write, drag the downloaded .pixiboard.json file into PixiNotes and connect the imported copy to the sync folder.   1. 60–67 · Demo 1

    Booth Builder

    Load Fortress. Click Open the doors, then Skip to jump to the result if time is tight. Select Open side and click midway down the right-hand edge once. Run it again and compare the visitor counts.

    In the tested setup, visitors entering the booth went from 0 → 12 of 36 in the simulation. If the tool stalls, use the prepared booth comparison in the deck or PDF.

  2. 67–75 · Demo 2

    PixiNotes MCP

    Use the MCP client with the imported local rehearsal board and its sync folder connected.

    “On the local Campfire v2 rehearsal board, create an Ideas/Bubbles card titled ‘Live MCP test’. Add the idea ‘Compare planned hours with booked hours for one example project.’”

    Confirm that the card and idea appear in PixiNotes. If the live write stalls, show the prepared MCP example Bubbles card.

  3. 75–90 · Q&A

    Questions and a possible pilot

    Take questions aloud and capture them in Your questions. In the last few minutes, ask VAVE to choose an owner and one measurable success criterion for a possible pilot. Record both in Next test.

    If PixiNotes is unavailable, take questions and record the decision in a local text file.
