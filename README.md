# Playing with Fire · stories around the fire

A 90-minute campfire talk about AI, vibecoding and working with many repos, for a team that designs communication in
space (showrooms, trade-fair booths, brand spaces). Eight chapters told like stories around a fire:

1. The gathering · 2. Old fires · 3. Words by the fire · 4. Kindling · 5. Many fires · 6. A fire for VAVE · 7. Smoke · 8. Embers

**Open it:** <https://hannespix.github.io/campfire/>

## What's in here

These are the built, self-contained files. Every page works offline, on a phone, and inside a PixiNotes board.

| Path | What |
|---|---|
| `index.html` | the hub: chapters, decks, tools, PDFs, pixel art |
| `decks/` | eight reveal.js decks, one per chapter (press **S** for speaker notes, **T** for a light theme) |
| `modules/` | eight live tools: Myth or Fact?, Token Oracle, Context Circle, Words, Prompt Forge, Git Time Machine, Fireplace Check, Booth Builder |
| `pdf/` | every deck as a PDF handout |
| `art/` | pixel art as SVG (animated in steps, still with reduced motion) and PNG |
| `boards/campfire-stage.pixiboard.json` | presentation layout for the original talk with wide chapter cards and a two-row trail |
| `campfire.pixiboard.json` | the original PixiNotes board layout |

Drop either board file onto the canvas in [PixiNotes](https://hannespix.github.io/pixinotes/) to import it as a new board. Use **More → Present** to start the talk.
Run `python3 boards/build_stage.py` to regenerate the stage board from the original export and artwork.
